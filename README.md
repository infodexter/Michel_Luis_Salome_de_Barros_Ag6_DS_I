# Sistema de Desconto Progressivo

Programa desenvolvido em Python para calcular descontos progressivos de acordo com o valor total de uma compra.

## Regras de desconto

- Compras abaixo de R$ 200,00: 5% de desconto.
- Compras de R$ 200,00 até abaixo de R$ 300,00: 10% de desconto.
- Compras a partir de R$ 300,00: 15% de desconto.

## Tecnologias utilizadas

- Python

## Funcionamento

O programa solicita ao usuário o valor total da compra, identifica o percentual de desconto correspondente, calcula o valor do desconto e apresenta o valor final a ser pago.

## Exemplos

| Compra | Desconto | Valor a pagar |
|---:|---:|---:|
| R$ 150,00 | 5% | R$ 142,50 |
| R$ 200,00 | 10% | R$ 180,00 |
| R$ 300,00 | 15% | R$ 255,00 |
